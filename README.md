# yumy.io — Игры Чёрной дыры

3D-игра в жанре .io: управляй чёрной дырой в low-poly городе, поглощай объекты, расти и съедай соперников.
Раунд длится 2 минуты, побеждает тот, у кого больше очков.

Стек: Vite + JavaScript (ES-модули) + Three.js. Внешних файлов нет: все модели собираются кодом.

## Запуск в Visual Studio Code

1. Установите [Node.js](https://nodejs.org) (версия LTS), если его ещё нет. Проверка: `node -v`.
2. В VS Code: **Файл → Открыть папку** и выберите папку `yumy-io-3d` (ту, где лежит `package.json`).
3. Откройте терминал: **Терминал → Новый терминал**.
4. Выполните:
   ```
   npm install
   npm run dev
   ```
5. Откройте адрес из терминала (обычно http://localhost:5173) в браузере.

Открывать `index.html` двойным щелчком не нужно: без сервера Vite игра не запустится.

Чтобы проверить игру на телефоне в одной Wi-Fi сети, запустите `npm run dev -- --host` и откройте адрес «Network» с телефона.

## Управление

| Устройство | Как играть |
|---|---|
| ПК | Мышь: дыра идёт к курсору. Или WASD / стрелки |
| Телефон | Коснитесь экрана и ведите пальцем: появится джойстик |

## Правила

- Дыра съедает объекты, если их размер не больше 80% её диаметра. Съеденное даёт очки, дыра растёт.
- Дыра, которая на 15% крупнее другой и накрывает её центр, съедает соперника: +очки и +1 к «Убийствам».
- Съеденного соперника возрождает через 3 секунды в другом месте, он сохраняет 30% очков.
- Стрелки у краёв экрана показывают, где соперники. Большая стрелка означает, что соперник крупнее вас.

## Настройки баланса

Всё в одном файле `src/config.js`: скорость дыры, скорость роста, число ботов, длительность раунда,
время возрождения. Измените значение и обновите страницу.

## Структура проекта

```
yumy-io-3d/
├─ index.html
├─ package.json
└─ src/
   ├─ main.js        точка входа, рендер-цикл
   ├─ config.js      настройки баланса
   ├─ game.js        меню → раунд → итоги, таймер, боты, поедание дыр, респавн
   ├─ hole.js        чёрная дыра (stencil-вырез в земле, рост, подпись)
   ├─ absorb.js      поглощение объектов, сетка поиска, анимация падения
   ├─ world.js       генерация города: улицы, кварталы, парки, крыши
   ├─ props.js       фабрика low-poly объектов
   ├─ traffic.js     движение машин и пешеходов
   ├─ ai.js          поведение ботов
   ├─ camera.js      камера сверху, слежение и зум
   ├─ input.js       мышь, клавиатура, виртуальный джойстик
   ├─ indicators.js  стрелки соперников за экраном
   ├─ ui.js          HUD, лидерборд, меню, экран итогов
   └─ styles.css
```

## Сборка

`npm run build` создаёт папку `dist` со статическим сайтом, её можно выложить на любой хостинг.
`npm run preview` запускает собранную версию локально.

## Публикация на GitHub Pages

1. Загрузите проект в репозиторий на GitHub (папку `node_modules` загружать не нужно, она в `.gitignore`).
2. Выполните `npm run build`.
3. Выложите содержимое папки `dist` в ветку `gh-pages` (например, командой `npx gh-pages -d dist`)
   и включите Pages в настройках репозитория: Settings → Pages → Branch `gh-pages`.

## Если что-то пошло не так

- **Белая страница с текстом «02:00»**: вы открыли `index.html` как файл. Запустите `npm run dev`.
- **Ошибка в консоли браузера**: откройте консоль (в Safari: Разработка → Показать консоль JavaScript) и пришлите текст ошибки.
- **Тормозит на телефоне**: в `src/world.js` уменьшите `N` (число кварталов), например с 5 до 4.
